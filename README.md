# Machine Learning From Scratch

This repository contains my implementations of basic Machine Learning algorithms from scratch using Python and NumPy.

I built these implementations to understand what happens behind the algorithms instead of directly using ready-made implementations from Scikit-learn.

## Algorithms Implemented

### K-Nearest Neighbors (KNN)
- Calculated Euclidean distance
- Found the nearest data points
- Used K nearest neighbors
- Applied majority voting for classification

### Linear Regression

Implemented Linear Regression using:
- Gradient Descent
- Ordinary Least Squares (Normal Equation)

### Logistic Regression

Implemented Logistic Regression using:
- Sigmoid function
- Probability calculation
- Gradient Descent
- Weight and bias updates
- Binary classification

## Why I Built This

The main goal of this repository is to understand the **logic and mathematics behind machine learning algorithms**.

Instead of just using:

`model.fit()`

and

`model.predict()`

I wanted to understand what actually happens inside these steps and how the model learns or calculates its parameters.

## Technologies Used

- Python
- NumPy
- Jupyter Notebook

## Learning Approach

I am implementing each algorithm step by step to understand:

- How the algorithm works
- The mathematics behind it
- How predictions are made
- How parameters are calculated or updated
- When the algorithm can be used

These implementations are mainly for learning and building a strong understanding of machine learning fundamentals.
